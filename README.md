# Payder

Payder — веб-приложение на FastAPI с регистрацией, профилями, карточками и общей лентой.

## Быстрый запуск в GitHub Codespaces

Откройте [README_CODESPACES.md](README_CODESPACES.md) и выполните шаги. В репозитории уже добавлена
конфигурация `.devcontainer` для установки зависимостей и запуска приложения на порту 8000.

## Локальный запуск

1. Установите Python 3.11 или новее.
2. Создайте и активируйте виртуальное окружение:

       python -m venv .venv
       .venv\Scripts\activate          (Windows)
       source .venv/bin/activate       (macOS/Linux)

3. Установите зависимости:

       pip install -r requirements.txt

4. Создайте файл настроек:

       copy .env.example .env          (Windows)
       cp .env.example .env            (macOS/Linux)

   В .env обязательно задайте уникальный SECRET_KEY и надёжный ADMIN_PASSWORD (не короче 12 символов). Для этого можно
   выполнить: python -c "import secrets; print(secrets.token_urlsafe(48))"

5. Запустите сервер:

       python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000

6. Откройте http://127.0.0.1:8000 и зарегистрируйте аккаунт.

## Важно при обновлении старой версии

Старая версия использовала фиксированного демо-пользователя и демо-карточки.
Новая версия не создаёт демо-данные. Если вы обновляете уже распакованный
старый проект, остановите сервер и удалите старый файл data/payder.db,
затем запустите приложение заново. Это удалит прежнюю локальную базу,
включая демо-пользователей и карточки. Сделайте резервную копию, если в
ней есть нужные данные.

## Функциональность

- Регистрация по имени, логину и паролю (от 8 символов).
- Вход и выход; сессия хранится в подписанной HttpOnly cookie.
- Пароли хранятся в виде PBKDF2-SHA256 хешей, не в открытом виде.
- Каждый пользователь работает со своим профилем.
- Карточки сохраняются в SQLite и привязаны к создавшему их аккаунту.
- Активные карточки появляются в общей ленте для других пользователей.
  Собственные карточки скрыты из собственной ленты.
- Реквизиты не входят в публичную ленту и возвращаются только после
  нажатия «Помочь».
- Пользователь может иметь до трёх активных карточек.
- Демо-пользователи и демо-карточки не создаются.

## API

```text
POST /api/auth/register
POST /api/auth/login
POST /api/auth/logout
GET  /api/profile
PUT  /api/profile
GET  /api/cards
POST /api/cards
POST /api/cards/{public_id}/view
POST /api/cards/{public_id}/help
```

## Тесты

    pytest -q

## Архитектура

```text
app/api         HTTP API и авторизация
app/core        настройки и криптографические функции
app/database    модели, подключение, CRUD
app/menu        пункты навигации, банки, категории
app/schemas     Pydantic-схемы
app/static      frontend (HTML/CSS/JS)
tests           автотесты
main.py         точка входа
```

Перед публикацией в интернете настройте HTTPS, уникальный SECRET_KEY,
надёжный пароль администратора и резервное копирование базы данных.
