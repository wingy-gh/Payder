# Payder

Payder — веб-приложение на FastAPI с регистрацией, профилями, карточками и общей лентой.

## Быстрый запуск в GitHub Codespaces

Откройте [README_CODESPACES.md](README_CODESPACES.md) и выполните шаги. В репозитории уже добавлена
конфигурация `.devcontainer` для установки зависимостей и запуска приложения на порту 8000.

## Локальный запуск

См. `readme.txt`. Для работы необходимы Python 3.11+ и переменные `SECRET_KEY` и `ADMIN_PASSWORD`
в локальном `.env`.

## Важно

Codespaces предназначен здесь только для тестирования. Не вводите настоящие банковские реквизиты
или иные чувствительные данные. Не коммитьте `.env`, базу данных и резервные копии.
