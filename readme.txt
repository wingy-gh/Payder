Payder
======

Сервис взаимной помощи: лента карточек со свайпом, реквизиты автора,
профиль, статистика и создание запросов. Интерфейс повторяет Figma-референс
https://exact-target-40091413.figma.site/

Запуск
------

1. Установите Python 3.11 или новее.
2. Создайте виртуальное окружение:

       python -m venv .venv

3. Активируйте его:

       .venv\Scripts\activate          (Windows)
       source .venv/bin/activate       (macOS/Linux)

4. Установите зависимости:

       pip install -r requirements.txt

5. Скопируйте пример настроек и задайте пароль админки:

       copy .env.example .env          (Windows)
       cp .env.example .env            (macOS/Linux)

   В .env укажите ADMIN_PASSWORD и SECRET_KEY.

6. Запустите сервер:

       python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000

7. Откройте приложение:

       http://127.0.0.1:8000
       Админка: http://127.0.0.1:8000/admin

При первом запуске создаётся SQLite-база data/payder.db и наполняется
демо-данными (пользователь Алексей Морозов и карточки из макета).

Тесты
-----

    pytest -q

Основные сценарии
-----------------

- Карточки: свайп влево пропускает, вправо открывает реквизиты автора.
  Реквизиты не отдаются в ленте, только после действия «Помочь».
- Профиль: имя, телефон и банк сохраняются через PUT /api/profile.
- Статистика: суммы и просмотры считаются из базы, период
  неделя / месяц / год переключается в интерфейсе.
- Создать: публикация карточки пишет запись в БД и сразу показывает её
  другим пользователям в ленте. Свои карточки в ленте скрыты.
- Админка: вход по ADMIN_PASSWORD, модерация (скрыть/показать карточку).

Архитектура
-----------

app/admin       административная панель
app/api         HTTP API
app/core        настройки и сиды
app/database    модели, подключение, CRUD
app/menu        пункты навигации, банки, категории
app/schemas     pydantic-схемы
app/static      frontend (HTML/CSS/JS)
tests           автотесты
main.py         точка входа
